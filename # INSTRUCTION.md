# INSTRUCTION.md — Premium SEO Taxi Website

## Project Goal
Build a premium, lightweight, SEO-first static taxi booking website for district-to-district cab service.

Target:
Rank for searches like:
- cab from tirupur to coimbatore
- tirupur taxi service
- one way cab tirupur
- tirupur airport taxi

Website must feel premium, handcrafted, elegant, and modern.

NOT generic AI-generated.
NOT template-looking.
NOT bulky.

Must be:

- premium

- mobile-first
- conversion focused
- SEO optimized

Luxury automotive + premium agency aesthetic.
